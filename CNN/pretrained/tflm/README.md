# On-MCU inference (TensorFlow Lite Micro on STM32F4)

The distilled int8 raindrop student runs on the microcontroller. No PC in
the loop: the MCU captures the frame, classifies each 48 px tile, and
triggers the wiper itself. The heater path is unchanged from `main.c`.

## Files

| File | Role |
|---|---|
| `raindrop_inference.cc/.h` | TFLM setup (6-op resolver, 48 KB arena), tile quantization, coverage loop, DWT cycle timer |
| `camera_dcmi.c/.h` | OV7670 over DCMI + DMA, QQVGA RGB565 snapshot, RGB888 conversion |
| `main_raindrop.c` | The firmware main: temperature -> heater, capture -> CNN -> wiper, status over USART2 |
| `raindrop_student_int8.cc/.h` | Generated by `python -m pretrained.to_tflite ... --name raindrop_student` |

## Build (STM32CubeIDE)

1. In `Final.ioc` enable DCMI (8-bit, snapshot), a DMA2 stream for DCMI,
   I2C1, and a 12-24 MHz MCO or PWM output for the camera XCLK. Regenerate.
2. Add `tflite-micro` as a source folder. The easy way: run
   `python tensorflow/lite/micro/tools/project_generation/create_tflm_tree.py -e hello_world /path/to/tflm_tree`
   in a tflite-micro checkout, then import `tflm_tree/` into the project.
   Set the language to C++17 for those files, add `-DTF_LITE_STATIC_MEMORY
   -DTF_LITE_MCU_DEBUG_LOG -DCMSIS_NN` and include `tflm_tree/`,
   `tflm_tree/third_party/flatbuffers/include`, `third_party/gemmlowp`,
   `third_party/kissfft`, `third_party/ruy`.
3. Copy this folder and the generated `raindrop_student_int8.cc/.h` into
   `Core/Src` / `Core/Inc`. Exclude the original `main.c` from the build and
   use `main_raindrop.c`.
4. Link with `-lm`, `-specs=nano.specs -u _printf_float` so the status line
   prints floats.

## Memory

| Buffer | Bytes |
|---|---|
| RGB565 DMA frame 160x120 | 38,400 |
| RGB888 frame | 57,600 |
| TFLM tensor arena | 49,152 |
| Model in flash | `g_raindrop_student_len` (about 25 KB at width 1.0) |

Total SRAM about 150 KB of the F4's 192 KB. If it does not fit alongside
the HAL and stack, drop the RGB888 buffer and convert per tile, or use
`--width 0.5` for the student. `MicroInterpreter::arena_used_bytes()` after
`AllocateTensors()` reports the true arena need; shrink `kArenaBytes` to it.

## Recording the numbers

Every status line prints `nn_us`, the DWT cycle-counter time for the
six-tile pass, and `cover`, the fraction of raindrop tiles. Log USART2 with
`screen /dev/tty.usbmodem* 115200` during a test and average `nn_us` for
the latency figure. Accuracy comes from comparing the printed `grid` against
what you see on the lens per frame.
